---

## Memory

Read both buffers before anything else. They hold everything this runs on: proposals come only from what they contain, extrapolated forward. Nothing else feeds this run.

## Proposals

Each proposal is a title plus a short description naming the buffer entries it grows out of. A subject may span topics or take an unconventional angle, but it must be anchored in something the memory holds.

## The bar

A proposal must be worth writing and worth reading as an article. There is no target count: if the memory cannot support anything worth publishing, say so plainly, name what is missing, and stop. Filler is failure; none is an answer.

## Output

Proposals live in the chat. Nothing is written to disk; picking one happens in conversation and can become the subject of a later write run.
